## 保留与恢复

- 所有局部修改保持项目 ID、15 个组件 ID、顺序及全局配置；每轮仅 1 个目标组件变化，其余 14 个组件完整相同。
- 新建独立作品后，插入闲聊，再返回设计结果：单轮撤销完整恢复上一作品；重做完整恢复新作品。两次 JSON 对比均无差异。
- 数学题、问候、一般知识问答：直接回复，设计工具调用为 0，未触发画布检查、自动应用或配置变化。
- 生成期间手动修改项目名：原稿保留人工修改，代理结果留作未应用草稿；再次设计不能绕过冲突保护。
- 有冲突草稿时插入普通问答：仍为 0 次设计调用；返回草稿后“应用”保持禁用，原稿与草稿均保留。
- 收起草稿后，原稿不变，并清理旧计划与错误提示。
- 预览中点击水泵标签，正确显示流量、压力与效率的弹层；返回后图表恢复，重置视角可返回完整园区。

## 已修复

1. 删除普通回复后强制执行设计工具的行为；最新请求独立发送，历史设计指令仅作为背景。
2. 普通聊天保留上轮结果、草稿、撤销入口和执行记录；可返回上轮设计，不自动应用待处理草稿。
3. 预设皮肤不再覆盖用户明确设置的数字颜色；主文字颜色同步尊重组件配置。
4. 在执行计划前验证验收条件类型，阻止 `exists=null`、缺少目标 ID、无效组件数量等条件进入执行。
5. 不支持的组件字段返回实际可编辑字段，避免模型因猜错字段而放弃或反复重试。
6. 独立新项目不再将上一项目的组件计为“删除”；GLB 反馈说明实际模型资源与预设字段的不同用途。

# 空间模板与极简对话

## 本地预览

- `/templates/regions/`：真实行政区矢量挤出地图。支持中国、日本及省级区域聚焦、区域点选与指标详情。国家、省份、挤出高度、光效和镜头可配置。
- `/templates/gis/`：Leaflet 地图。默认 Esri 卫星影像，可切换 OpenStreetMap 街道图；支持监测点、覆盖范围、缩放、复位及详情。底图需要联网。
- `/templates/machine/`：程序化风机传动总成。主轴、轴承、行星齿轮、联轴器、发电机与叶轮；支持运行、剖面、平滑拆解、线框和点击部件详情。

三套作品均为设计器原生组件，可从模板市场使用，支持配置导出、场景编辑与智能体增量修改。构建输出包含相应静态 HTML 入口。

GIS 数据使用设计器统一的数据运行时；点位字段为 `name / lat / lng / value / oxygen / status / radius`，其中 `radius` 单位为米。内置业务数据与覆盖范围均为演示信息。地图来源、边界简化说明与许可见 [数据授权](../public/assets/maps/ATTRIBUTION.md)。

## 对话

用户消息右对齐，助手回复左对齐。工具调用、方案、变更清单和评估卡片不出现在对话中；内部检查、自动应用、异常草稿恢复与撤销继续保留。

浏览器与 Worker 使用 SSE；Worker 增量解析 OpenAI 兼容接口与 Anthropic 流，工具参数按调用序号拼接，不发送到聊天气泡。支持 UTF-8 跨字节分块、CRLF、心跳、响应大小限制、中断取消和未完成连接检测。回复正文按真实网络增量显示，滚动跟随可以被用户主动滚动打断。

默认简体中文。只有明确指定其他回复语言时切换。对以外语回答默认中文请求的情况，先拦截外语正文，再用不含设计工具的独立请求改写为中文，并继续流式输出；改写费用和 tokens 纳入本轮统计。通常的中文回复不增加这一步请求。代码块、数字等不被误判为需要翻译的正文。

## 地球改色修复

过去组件强调色仅影响 CSS 装饰，Three.js 没有读取该覆盖色，球面也使用固定底色。

现在 `globe.props.surfaceColor` 直接控制球面实际材质；组件强调色同步到轮廓、光晕与场景效果。兼容已有仅修改强调色的项目。改色原地更新材质，不重建球面几何体。场景编辑器与画布共用同一渲染链路。

`inspect_runtime` 返回 `appearance.surfaceColor`，来自实际 Three.js 材质。若配置颜色与实际材质不一致，运行检查返回错误，阻止自动应用。自定义代码替换的场景单独标记为 `custom-code`，不会冒用基础球面的检查结果；智能体也不能通过修改已被替换的基础 surfaceColor 冒充完成自定义场景改色。

## 验证

- `npm test`：完整回归，包含新模板、流式协议、中文回复和实际材质验证。
- `npm run build`：前端、静态路由与 Worker 构建。
- 真实默认模型：机械模板只修改标题，14 个组件中其余 13 个配置完全一致。
- 截图复现“地球颜色改为红色”：实际球面材质变为 `#e02020`，其余 11 个组件配置完全一致，结果中文回复并自动应用。
- 英文知识提问：默认中文答复，零设计工具调用。
- 本机均衡模式测量：行政区约 149 次绘制、22,640 三角形；机械约 87 次绘制、17,800 三角形，约 30 FPS。具体性能随设备与视口变化。

未发布到任何远程环境。
